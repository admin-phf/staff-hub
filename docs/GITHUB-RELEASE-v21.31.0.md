# Staff Hub v21.31.0 — Reconcile CH2 Order Tasks 12–16: one steps + downloads row, wider search / table, step explanations with real previews and versions, on-page POSActive notice, aligned headers (20 Oct 2026 20:30 AEDT)

**Summary:** v21.31.0 — implements the Reconcile CH2 Order addendum (Tasks 12–16). The four downloads sit on the same row as the three step pills; the receiving tools, a full-width search and the view buttons form one toolbar above a full-width table; every step explains what it does, what it needs, what it checks / produces and its output, with technical detail folded under "How it works" and step 3 previewing the real export columns; the POSActive "no eligible rows" guard shows on the page instead of a browser pop-up (same rule, same wording, still no file); and panel, input-card and step headers share one right-edge layout. A real reconciliation of two invoices was run on this version and on the committed v21.30.1, and every export file is identical. No change to reconciliation, matching, arithmetic, discount audit, exports, filenames or the Library.

## Changes by task
- **Task 12 — toolbar and work area.** The four downloads (POSActive Import.txt, Full Reconciliation.xlsx, Full Reconciliation.csv, POS key review.csv) moved onto the step row: steps left, downloads grouped right, same 34 px gold pills; one row from roughly a 1,360 px window, below that the downloads move together to a right-aligned second line. Visible labels drop the word "Download" (the ↓ arrow shows it; each button's accessible name keeps "Download …"); the POSActive button still changes to Exceptions.xlsx in the Exceptions view and hides in All lines, as before. Counter, Tick all, CLEAR QTY, Remove not supplied, search and View form one toolbar directly above the table; the search's 460 px cap was removed so it takes the remaining width. The table uses the full content width; sorting, sticky header, horizontal scroll and every quantity / tick interaction are unchanged. The POSActive guard (no supplied rows) now shows as a dismissible on-page notice with the original wording under the step row instead of a browser alert; the rule is unchanged, no empty file is created, and the other three downloads stay available.
- **Task 13 — step explanations, previews, versions.** Each step group shows "What this does", Needs · Checks / produces · Output (steps 1–2 state "No download produced"), and a folded "How it works". Every statement was checked against the source (e.g. the link order barcode → PLU → CH2 code = POS Sub ID → supplier-update barcode → supplier code = Sub ID with description only as a LOW fallback, and "a wholesale-price match alone never links a line", from core/reconcile.js). Step 3's previews list the real column contracts read at runtime from the export code — POSActive import 15 columns (PHF.posImport.CONTRACT.headers) and full reconciliation 43 columns (PHF.schema.HEADERS); nothing generated or invented, and opening a preview runs nothing. The Steps panel shows the page version and the engine build constant (PHF.schema.BUILD: Integrity Engine v2.6.38, 2026-10-01); no per-step versions exist in the code, so none are shown. The header Run pills no longer repeat the status — the header badge carries it once.
- **Task 14 — inputs and intro.** POS / master, Ongoing Discounts, POS back-end order and Supplier invoices cards use the shared collapsible head (group label · gold title · description · badge · chevron). The drop zone is compact (≈70 px), file rows are single lines with Remove, and Used by / Storage / Status fold into one "Used by · Storage · Status" line. Multi-file drop, validation, storage and readiness counts unchanged. The one-line intro keeps the local-processing note with less padding; the privacy warning at the foot is kept.
- **Task 15 — headers and alignment.** Every step / database group header in all three tools now reads action button → status badge → chevron, so the badge always sits beside the chevron. Reconcile's Saved files panel had its navy band inside a white margin (theme.css forces 16 px padding on direct workspace panels); it now matches the other tools. Badges never shrink or clip. Strip pills, checklist step pills and header Run pills share one state.
- **Task 16 — shared CSS.** The new pieces live in assets/css/phf-ui.css v1.3.0 (step-row downloads, work-area toolbar, on-page notice, step facts / folds, compact input cards, one right-edge cluster). Two `!important` declarations were added, each only overriding theme.css's existing `!important` padding on Reconcile's Saved files panel. Build POS Master and POS New Product Check Clean pick up the header-order change.
