Files the tools save for each other, so you don't drag them in again: Build POS Master Databases saves the POS Database, the supplier imports and the merged masters when a build finishes; reference files you load once are kept here too (Ongoing Discounts is one file for Build POS Master Databases, Reconcile CH2 Order and POS New Product Check Clean). Reconcile CH2 Order and POS New Product Check Clean load the POS files automatically; the CH2 / Unique supplier imports go into a merge only when you press Add there, so each merge covers just the brands you choose. Supplier Contacts keeps its list here — Delete all leaves it in place (use its own ✕), so download it from Supplier Contacts to share or back it up. Everything stays in this browser on this computer — nothing is uploaded, and another browser or PC has its own Library.

Privacy: do not commit customer, invoice, order or other business data to this repository. The reconciliation tool is intended to process files locally in the staff member's browser. Notices are published encrypted (data/notices.enc.json) and read with the staff passphrase.
