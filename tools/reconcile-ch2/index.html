More detail — review notes, order link, import keys, how the checklist works
Receiving checklist · Add Qty accumulates in Found · Enter moves to the next Add Qty row · exact Found = invoiced/supplied qty completes automatically · under/over counts stay in Remaining until resolved or manually ticked · if an exact count is later corrected short/over it returns to Remaining; only a left-checkbox manual acceptance stays completed · unticking a row clears Found so a miscount can be restarted · unticked rows are treated as not supplied in the POSActive download · the POSActive download imports each row's Found quantity (overs and unders) with the CH2 invoice prices · a ticked not-invoiced row with Found > 0 is added to the POSActive download as a manual receiving line · Tick all covers POS-order rows; INV rows (billed but not on the POS order) are held in their own section at the top and stay excluded from the TXT until ticked individually · Not on POS order explains why each INV row was not matched · enter 0 to clear Found and account for none supplied · Clear qty is above Add Qty · click sortable column headings to reorder Remaining and Completed sections · Total inc GST = receiving qty × AdjCatPrc + GST · POS Index preserves the original POS-order sequence · CH2 Line identifies supplier invoice lines · Found: red = under, grey = correct, green = over
